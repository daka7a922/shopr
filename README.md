# Shopr 🛒

A full-stack e-commerce application built with **Spring Boot** and **React**.

> 🚧 **Status:** Early development. Things will change.

## Planned Features

- Authentication and role-based access control (JWT)
- Product and category management
- Shopping cart
- Order placement
- Address management
- Online payments (Stripe)
- AI-powered features (Spring AI)

## Architecture

**Backend:** a layered structure, `Controller → Service → Repository → Database`.
Each feature (Address, Auth, Cart, Category, Order, Product) has its own controller, service, and repository.

**Frontend:** React TBD

## Tech Stack

### Backend
- Java, Spring Boot, Spring Security
- JWT and role-based access control (RBAC)
- Spring Data JPA, Hibernate
- PostgreSQL / MySQL
- Lombok, Maven/Gradle
- Swagger (OpenAPI) documentation
- Spring AI
- AWS deployment

### Frontend
- React, JSX, Redux
- React Router, React Hook Form
- Tailwind CSS (responsive design)
- Stripe integration
